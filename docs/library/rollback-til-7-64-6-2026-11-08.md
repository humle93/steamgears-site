# Rollback er muligt: 7.64.6 ligger i git-historikken, ikke kun i et håb

Status: målt og afprøvet 8/11 2026. Retter den hidtidige antagelse i
[`live-7-64-9-2026-11-08.md`](live-7-64-9-2026-11-08.md), hvor der stod at 7.64.6 ikke kan rulles tilbage
»uden den gamle zip«.

## Påstanden der var forkert

`AGENTS.md` §7.3 kræver **præcis én zip** i `plugins/` — den aktuelle version — og `plugin-ci.yml` fejler
hvis der ligger flere. Derfor blev 7.64.6-zip'en slettet i samme commit som 7.64.9 blev lagt ind. Det blev
læst som: »så findes den gamle version ikke længere«. Den findes, den ligger bare i historikken i stedet for
i arbejdstræet, og det er hele forskellen.

## Den målte vej

```bash
# 1. find commit'en hvor 7.64.6-zip'en blev slettet
git log --oneline --diff-filter=D -- 'plugins/steamgears-autopilot-v7.64.6.zip'
#    e9c13fd Pinterest: tokenkilden bestemmer hvem der må forny (7.64.7)

# 2. hent zip'en som den så ud i forældre-commit'en (før sletningen)
git show e9c13fd^:plugins/steamgears-autopilot-v7.64.6.zip > /tmp/sgap-7.64.6.zip

# 3. bekræft at arkivet er intakt og bærer den rigtige version
unzip -t /tmp/sgap-7.64.6.zip
unzip -p /tmp/sgap-7.64.6.zip 'steamgears-autopilot/steamgears-autopilot.php' | grep -o "Version: [0-9.]*"
```

Målt 8/11 2026:

| Måling | 7.64.6 (fra historikken) | 7.64.9 (i `plugins/`) |
| --- | --- | --- |
| Størrelse | 375 815 bytes | 385 602 bytes |
| SHA-256 | `a7399406…69e6c2d` | `4fb6483b…d196b85` |
| `unzip -t` | OK | OK |
| Poster | 48 filer | 49 |
| Header | `Version: 7.64.6` | `Version: 7.64.9` |

Tallet på 7.64.9 er det samme som i [`release-preflight-2026-11-08.md`](../../reports/release-preflight-2026-11-08.md).

## Sådan rulles der tilbage i praksis

1. Hent zip'en som ovenfor (eller `git checkout <sha> -- plugins/steamgears-autopilot-v7.64.6.zip`).
2. I wp-admin: **Plugins → Tilføj nyt → Upload plugin** med 7.64.6-zip'en, og vælg »Erstat nuværende«.
   WordPress accepterer en ældre version ved upload, mens selvopdateringen ikke tilbyder den.
3. Bekræft bagefter: `Version: 7.64.6` i `steamgears-autopilot.php` på sitet, og at `site-health` svarer.

Læg **ikke** den gamle zip tilbage i `plugins/` som fast fil: så fejler `plugin-ci.yml` på reglen om én zip,
og selvopdateringen kan ikke afgøre hvilken version der er aktuel. Historikken er arkivet.

## Hvad der stadig er ejerens valg

Om der skal en egentlig arkiv-politik (fx en GitHub Release pr. version, så zip'en har en stabil URL og en
menneskelæsbar liste). Indtil da er git-historikken tilstrækkelig og kræver ingen nye filer i `plugins/`.
