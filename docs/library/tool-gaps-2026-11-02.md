# Hvilke værktøjer mangler — 2/11 2026

Research af det værktøjsgab, der stod tilbage efter at de 17 kladder var udgivet. Skrevet efter et gennemløb hvor vi ramte fem konkrete blokeringer, ikke som en ønskeliste.

## 1. Udgangspunktet: hvad vi faktisk har

Royal MCP svarer med **270 værktøjer** på siten. Fordelingen er ikke tilfældig:

| Område | Antal | Dækker |
|---|---|---|
| `wp_*` | 105 | Indhold, sider, medier, menuer, meta, brugere, kommentarer, options |
| `wc_*` | 29 | Produkter, varianter, attributter, ordrer, kuponer, kunder |
| Elementor / Divi | 23 | Sidebygger-indhold |
| Backup (SiteVault, UpdraftPlus, Duplicator) | 17 | Backup og gendannelse |
| Sikkerhed (Wordfence, Solid, AI Firewall) | 15 | Logs, bot-politikker |
| SEO (Yoast, Rank Math via `wp_update_seo_meta`) | 6 | Titel, description, fokusord pr. post |
| Redirection, WPForms, Complianz, MonsterInsights, cache | ~20 | Redirects, formularer, samtykke, GA, cache |

Det er en **indholds- og handelsmaskine**. Det er ikke en **driftsmaskine**. Alt nedenfor er konsekvenser af den forskel.

Søgning i værktøjslisten giver nul træf på: `indexnow`, `search console`, `sitemap`, `transient`, `price`, `currency`. To træf på `cron`, begge læsende.

## 2. De fem huller vi ramte i praksis

### A. Sitemap og indeksering — vi kan skrive indhold, men ikke bede om at få det indekseret

I dag udgav vi 17 produkter og en ny side. Sitemappen viste stadig 39 produkter og ingen `/inspiration/`. Årsagen er Rank Maths egen sitemap-cache, og der findes **intet værktøj** i MCP'et til at rydde den, regenerere den eller se dens status.

Mere generelt mangler hele indekseringslaget: ingen IndexNow, ingen Search Console, ingen URL-inspektion.

**Det der lukker hullet:**

| Værktøj | Hvad det giver | Pris | Vurdering |
|---|---|---|---|
| Rank Math → Instant Indexing | IndexNow til Bing, Yandex, Naver, Seznam ved publicering | 0 kr. (i free) | **Tag den først.** Ren gevinst, ingen kode |
| Google Search Console API | Faktiske visninger, dækning, URL-inspektion (2.000/pr. dag) | 0 kr. | Nødvendig for at måle om noget virker |
| `bjornfix/mcp-abilities-rankmath` | 34 `rankmath/*`-abilities, bl.a. sitemap-status, URL-liste, rewrite-flush | 0 kr., GPL | Kan lukke cache-hullet delvist |
| Egen ability (WP 6.9 Abilities API) | Præcis den funktion vi mangler: ryd cache, kør cron, slet transient | 0 kr., ~20 linjer PHP | Den holdbare løsning, men kræver kodeadgang (se B) |
| Playwright MCP | Klikker på "Regenerate sitemap" i wp-admin som et menneske | 0 kr. | Sidste udvej; langsomt og tokens-tungt |

**Google Indexing API er ikke svaret.** Den er begrænset til `JobPosting` og `BroadcastEvent`. Produktsider hører ikke til, og kvoten tæller pr. URL. Plugins der lover "øjeblikkelig Google-indeksering" af produkter sender til et endpoint, Google siger ikke er til det.

### B. Kode- og filadgang — den strukturelle mangel

Vi kan ikke skrive PHP, ikke redigere theme-filer, ikke køre WP-CLI, ikke slette cache-filer. Det er ikke en forglemmelse: siten har **både Code Snippets og WPCode**, og MCP'et kan kun *læse* og *deaktivere* snippets — ikke oprette nye. Kodeudførelse er bevidst lukket.

Det er den rigtige standard for en agent med skriveadgang. Men det betyder også, at enhver mangel af typen "der findes ingen knap i REST-API'et" ender som en manuel opgave for ejeren.

**Det der lukker hullet:**

- **Officiel MCP Adapter + egne abilities.** WordPress 6.9's Abilities API gør en funktion til et MCP-værktøj i ~20 linjer PHP med sin egen `permission_callback`. Det er den tiltænkte 2026-vej, og Royal MCP publicerer allerede sine værktøjer gennem adapteren. **Advarsel:** Rank Math 1.0.279 bundler MCP Adapter 0.5.0, som kan overskrive standalone 0.7.0 og give "Missing Mcp-Session-Id". Test `/wp-json/mcp/mcp-adapter-default-server` før noget andet.
- **`mvtandas/wp-cli-mcp` over SSH.** 45+ værktøjer, herunder `wp_eval`, `wp_cli_raw`, theme-fil læs/skriv, `wp_cache_flush`, `wp_db_query`. Lukker B, og dermed også A og C halvt, på én gang. Prisen er **host-niveau tillid**: ingen pr. værktøj-scoping, så det kræver en dedikeret SSH-bruger og backup før brug.
- **Playwright MCP.** Det eneste der kan betjene wp-admin-skærme, som hverken REST eller abilities dækker. Microsoft-vedligeholdt. Brug persistent profil og en dedikeret admin-bruger.

**Anbefaling:** MCP Adapter + to-tre egne abilities (sitemap-cache, cron-kørsel, transient-oprydning) frem for SSH. Det er mindre blast radius end `wp_eval`, og det er den vej WordPress selv peger på.

### C. Billedproduktion — den største enkeltforbedring vi stadig mangler

P1.1 i roadmap'en står urørt: ingen produkter har 3+ billeder. Alle 56 har præcis ét. Vi kan uploade og knytte billeder, men ikke **lave** dem.

**Det der lukker hullet — og rækkefølgen betyder noget:**

| Produkttype | Motor | Pris | Hvorfor |
|---|---|---|---|
| T-shirts, plakater, telefoncovers | Printful / Printify mockup-API | **0 kr.** | Ægte printfelter, ingen tekst i billedet, ingen gætværk |
| Smykker, bælte, PDF-mønster | Dynamic Mockups (egne PSD'er) | **~0,05 kr./billede** ($15/md., 3.600 credits/år) | Eneste API med `laser_engrave` og `deboss` til metal og læder |
| Lifestyle/editorial | Gemini "Nano Banana" eller FLUX Kontext som *redigering* | ~$0,04/billede | Kun som pynt oven på et korrekt render |

**AI-generering løser ikke dette problem.** Ingen af modellerne tager imod en printfil plus et placeringsfelt. Designet bliver genskabt, ikke placeret: finker detaljer smitter, sømme og kraver opfindes, og modellerne skriver Care-labels og mærkenavne ind i billedet. Til plakater, hvor trykket *er* produktet, er det en direkte vildledning.

**Printfuls vilkår skal læses:** mockups må kun bruges til Printfuls egne produkter. Smykker og bælte må derfor ikke bruge Printful-billeder. Printful-URL'er udløber efter 72 timer, så billederne skal hentes ned.

**Regnestykke for 75 SKU'er × 4 billeder:** ~180 katalogbilleder til 0 kr., ~120 egne renders til ca. 6 kr. i alt, inden for abonnementet. **15–30 kr./md.** mod 5–25 kr./billede for en freelancer.

### D. Valuta og betaling — stadig USD i en dansk butik

Butikken prissætter i USD. Det er ikke bare et UX-problem; en EU-butik der viser dollarpriser inviterer til indsigelser om forbrugerpriser og moms. Der findes intet valutaværktøj i MCP'et, og kun Stripe som betalingsvej.

| Behov | Løsning | Pris |
|---|---|---|
| Basevaluta | Skift til DKK i WooCommerce → Settings → General **før** en switcher installeres | 0 kr. |
| EUR ved siden af DKK | Aelia Currency Switcher (faste priser pr. valuta, cache-håndtering, moms) | £89/år |
| Billigere alternativ | CURCY (VillaTheme) premium | $39–69 |
| MobilePay | Officiel `woo-vipps` + kortindløser | 0,59 % + 1 kr. nu, **0,89 % + 1 kr. fra 1/1 2027** |
| Kort + MobilePay i én aftale | Quickpay | 99 kr./md. + 49 kr./md. for MobilePay |

To ting at holde fast: **MobilePay-reservationer udløber efter 14 dage i Danmark** (fang før), og Stripe understøtter MobilePay, men ikke gentagne betalinger og ikke Dankort. Kør aldrig to valuta-motorer samtidig.

### E. Jura og identitet — samme svar som før, nu med værktøj

P0.3 og P0.6 har stået åbne hele tiden: CVR, firmanavn, adresse og telefon mangler, og GPSR-blokken henviser til "postal address on request".

| Behov | Løsning | Pris |
|---|---|---|
| Slå CVR op / validere | cvrapi.dk (navn, adresse, branche, ejere) | 0 kr., **50 opslag/dag pr. IP** |
| Mere end 50/dag | Datafordeleren CVR GraphQL (offentlige data er ikke adgangsbegrænsede) | 0 kr. |
| GPSR-felter pr. produkt | Lodestone Product Compliance (artikel-19-felter, bulk-tildeling, katalog-audit) | 0 kr. |
| EU-repræsentant, hvis nødvendig | Euverify | ~£39/md. |

GPSR kræver felterne **i selve tilbuddet**, ikke på en separat side. Lodestone gør det struktureret; den giver bevidst ingen "compliant"-badge, og det er rigtigt — ansvaret kan ikke købes for et plugin.

### F. Nøgleord → katalog → udrulning: hvad der faktisk kan automatiseres

Det her var den del af spørgsmålet der lød mest som et produkt, og mindst er det. **Der findes ikke ét værktøj der gør hele kæden.** Den deler sig i fire:

| Trin | Kan automatiseres? | Værktøj | Pris |
|---|---|---|---|
| Finde nøgleord + volumen | Ja | DataForSEO Labs (`keyword_ideas`) | $0,012/opgave + $0,00012/pr. resultat |
| Købsintention | Ja, men på SERP-form, ikke ordlister | DataForSEO SERP | $0,0006/opslag |
| Skrive teksten | Ja, med menneskeligt gennemsyn | LLM | få kr. |
| Publicere | Ja | WooCommerce batch-API (100 objekter/kald) | 0 kr. |
| **Bli' indekseret i Google** | **Nej** | Sitemap + crawl-budget + interne links | 0 kr. |
| Måle | Ja | GSC Search Analytics + URL Inspection | 0 kr. |

DataForSEO kræver **$50 minimumsindskud**, som ikke udløber — det holder i månedsvis ved vores volumen. Ahrefs ($129/md.) og Semrush (~€450/md.) er 10–30 gange dyrere for det samme på denne størrelse.

Og den vigtige grænse: Googles politik for **scaled content abuse** retter sig præcis mod "generér mange sider automatisk uden menneskelig værdi". AI-tekst skal gennem et godkendelsestrin, ikke publiceres i bulk.

## 3. Hvad vi ikke skal gøre

- **Ikke** pege Google Indexing API på produkter. Den er til jobopslag og livestreams.
- **Ikke** købe Ahrefs eller Semrush til en butik med 56 produkter.
- **Ikke** køre to valuta-plugins. Det giver forkerte totaler i ny og næ.
- **Ikke** bruge AI-genererede billeder i de rene mockup-slots. Brug dem som redigering oven på et korrekt render.
- **Ikke** give en agent `wp_eval` eller `execute_php`, før der er en dedikeret bruger, backup og en log nogen læser.
- **Ikke** købe en "GPSR compliant"-badge. Ansvaret følger produktet, ikke pluginnet.

## 5. Det der stadig kun kan afgøres af ejeren

1. CVR, firmanavn, adresse, telefon — blokerer P0.3 og P0.6, to lovkrav.
2. Basevaluta og prissætning i DKK/EUR — blokerer alle 56 priser.
3. Indløser til kort, hvis MobilePay skal køre ved siden af.
4. Om smykker og bælte skal fortsætte: de har ét billede, ingen bekræftet leverandør bag GPSR-linjen og en tynd marginhistorie.

## 6. Ikke verificeret

- Om Rank Maths cache kan ryddes gennem `bjornfix`-abilities eller kun gennem wp-admin-knappen. Dokumentationen viser sitemap-status og rewrite-flush, ikke en udtrykkelig cache-purge.
- Printfuls præcise rate limit på mockup-endpoints (ikke offentliggjort) og den fulde ordlyd af ToS §4.6 — læst gennem tredjepartsgengivelse, fordi deres docs overskrider fetch-grænsen.
- Om den officielle WooCommerce Stripe-plugin eksponerer MobilePay i dag.
- Om Rank Math/MCP Adapter-konflikten (0.5.0 vs 0.7.0) er løst efter 4. oktober 2026.
- CURCY's præcise premium-pris.
