## Regler

- Intet flyttes hertil uden at dets afløser står i tabellen.
- Arkiveret materiale tælles **ikke** som status og må ikke bruges som grundlag for procenter.
- Skal noget tilbage i brug, flyttes det ud igen og skrives ind i [`../README.md`](../README.md) — ikke bare
  linkes herfra.
- Git-historikken bevarer alt; intet er tabt ved oprydningen.
